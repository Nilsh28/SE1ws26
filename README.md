Statement U2:
Ein Nachteil ist, dass der Aufrufer den Rückgabewert explizit auswerten und interpretieren muss, um zu erkennen, ob ein Fehler aufgetreten ist. Der Compiler erzwingt das nicht, im Gegensatz zu einer geprüften Exception, die den Aufrufer zwingt, sich mit dem Fehlerfall zu befassen, sei es durch Abfangen oder Weiterreichen. Wird der Rückgabewert ignoriert oder nicht korrekt geprüft, bleibt der Fehler unbemerkt und kann sich unkontrolliert durch das Programm fortsetzen.
